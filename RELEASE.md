## Regenerating and checking the published tables and figures

Two scripts rebuild the tables and figures of the accompanying article from the result files and compare them with the article's own:

```bash
# Tables: rebuilt from package1, compared cell by cell with the article's LaTeX source
python experiments/release_tables.py --package <package1> --tex <article .tex> --out <out>/tables

# Figures and screening tables: the article's figure scripts run on package1
# (--waves <folder with results/wave1..wave4> runs them on the wave branches instead)
python experiments/manuscript_scripts.py --snapshot <article folder> --package <package1> \
    --figure-data <figure-data results/figure_data> --attachments <attachments> \
    --replace <patched conv_data.py> --tex <article .tex> --out <out>/figure_scripts

# The permeability figure
python scripts/plot_permeability_grid.py --out <out>/figures
```

**`release_tables.py`** builds each table from the result CSVs alone:
- the medians over seeds;
- the stopping markers;
- the ratios.

It writes one `<label>.csv` per table. It then reads the same table out of the LaTeX source and compares every cell. A number agrees when it lies within half a unit of its last printed digit; markers and text must be equal.

**`manuscript_scripts.py`** runs the article's figure scripts unchanged except for their input paths. It renders each regenerated figure beside the published one and compares the screening tables row by row.

**Result of the check for version 2.0:**

| Check | Result |
|---|---|
| Tables | 19 tables, 2,594 cells, all agree |
| Data figures | 20, all pixel-identical, both from the wave branches and from `package1` |
| Screening tables | 48 of 48 rows identical |
| Permeability figure | pixel-identical |

The regenerated files are in `package2-results`, `results/package2/G1_release/`.

## Notes on the result files

**`A_calibration/results/kovasznay_comparison.csv`** (commit ce0afda).
- The F1 error medians are the medians of the final errors recorded in `run.json`. An earlier version used the smallest logged error, which picks a step by the exact solution.
  - GPU `eps_u`: 4.19e-5 (was 4.11e-5).
  - CPU `eps_u`: 5.88e-5 (was 5.66e-5).
  - CPU `eps_p`: 3.45e-4 (was 3.42e-4).
- `eps_v` and `eps_p_meanfree` follow the same convention.
- Wave 4's copy under `fixes/option_b/section46` still holds the earlier medians. The comparison figure is the same with either copy.

**`four_method_controls.csv`** (the stall controls).
- Four of the six controls that depart from their original do so at the original's last logged row before the stall. Two depart 13–14 iterations before it:
  - `bl_P1024_NiL-Q_s2_cuda` departs at iteration 8,140; the original stalled at 8,153.
  - `burgers_P400_NiL-Q_s2_cuda` departs at 5,800; the original stalled at 5,814.
- `experiments/stall_control_departures.py` writes `stall_control_departures.csv` with every control.

**Gravity-influenced Buckley–Leverett, P = 64.**
- `package1` holds wave 4's rerun `bl_gravity_P64_cpu_paper`, which uses K_max = 60 and reaches its target at k = 43. Wave 2's run, with K_max = 20, did not reach it; see `WAVES.json`.
- The convergence figures need the patched `conv_data.py`, which accepts the rerun. The two curves agree to 1.1e-16, so the figures are the same either way.

**Run settings.** `experiments/b5_check.py` compares the settings table with every run's `run.json` (`b5_check.md`, `b5_actual.csv`).
